## SVC_EDIT

### `src/app/core/chat/chat-editing.spec.ts`

- **ChatService edit ops (insert / remove / delete)**
  - **delete cascade (remove subtree)**
    - deletes a leaf assistant and leaves the rest of the path intact
    - deletes a mid-tree answer and every descendant
    - deletes the root question and the entire tree
    - rejects delete of a missing node
  - **delete keepChildren (remove node only)**
    - reparents mid-tree children onto the deleted node's parent
    - promotes children of a deleted root to new roots
    - removing a leaf with keepChildren is the same as cascade
  - **insert (branch + reparent)**
    - inserts above a mid-tree question and hangs the old subtree under the new answer
    - inserts above the root question: new root, old root adopted under the new answer
    - inserts above a leaf question (no further descendants yet)
    - insert among several siblings adopts every previous sibling, not just the edited one
  - **reparentNodes fringe cases**
    - skips a self-parent request (no API write, tree unchanged)
    - moves a mid-tree node under another existing node
    - can lift a node to root by passing parentId null
  - **ensureDraftAtLeaf after delete**
    - does not spawn a draft while generation is frozen
    - creates a root draft after the last node is deleted once generation is cleared
    - adds a draft question under a remaining leaf answer
    - creates a draft leaf under the remaining question after deleting its answer (Delete Continuation)
    - creates a draft leaf when a chat’s seeds end on a user node (no greeting)
    - does not spawn a composer under a question that is mid-send (regression: no spurious leaves)
    - adds a draft leaf under an empty-text assistant chapter with an image attachment (image-only answer)
    - does NOT add a draft leaf under an empty assistant chapter whose only attachment is a non-image record
    - a second ensureDraftAtLeaf while one is in flight awaits the same operation (fixes batch stopping after lore sends)
  - **ensureDraftUnderAnswer (batch composer leaf)**
    - creates ONE composer leaf when the housekeeping effect races the batch loop
    - reuses an existing empty draft instead of adding a superfluous sibling
    - reuses a typed but unsent user child under the answer
    - does not hang a composer under a still-streaming empty answer
    - does not hang a composer under a non-assistant node
    - hangs a composer under an image-only answered chapter
  - **trash (soft delete / restore / purge)**
    - lists only the branch root in the trash after a subtree delete
    - restores a deleted branch back into the tree
    - purges a deleted branch permanently
  - **graceful stop (finish current stream, then stop)**
    - requestGracefulStop does NOT abort the running generation or the operation
    - hard Stop still aborts the operation and satisfies the between-step guard
    - a graceful stop is cleared when a new operation begins
    - a graceful stop is cleared when the operation ends
    - graceful stop does not leak into a later plain send (no operation)
    - chat-scoped Stop aborts THAT chat only and keeps it cancelled until its run ends
    - a Stop of the single running chat operation satisfies the between-step guard
