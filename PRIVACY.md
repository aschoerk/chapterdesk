# Privacy Policy for ChapterDesk

**Last updated:** October 2026

This privacy policy applies to the **locally installable desktop releases** of ChapterDesk.

## 1. Scope & Application Types
- **Locally Installable Releases:** This policy covers desktop releases installed directly on your local device.
- **Hosted / Cloud Deployments:** If ChapterDesk is deployed or accessed as a hosted web or cloud instance (e.g., via Google Cloud Platform or custom servers), server-side logging, network traffic, and data handling are subject to the policies of the specific hosting environment and server administrator.

## 2. Data Collection (Local Desktop Installation)
- **No Personal Data Collection:** The locally installed ChapterDesk desktop application does not collect, track, transmit, or monetize any personal user data, telemetry, or usage metrics.
- **Local Data Ownership:** All application data, story projects, workspace files, and local database records remain stored exclusively on your local device.

## 3. Third-Party API Connections
- If you configure ChapterDesk to connect to third-party Large Language Model (LLM) providers (such as OpenAI, Anthropic, or OpenRouter), prompt payload data is transmitted directly from your client to those endpoints.
- Those requests are governed solely by the privacy policies of the respective API providers. ChapterDesk does not route your requests through intermediate servers.

## 4. Contact
For questions regarding this privacy policy or the application's source code, please open an issue in the public GitHub repository.
