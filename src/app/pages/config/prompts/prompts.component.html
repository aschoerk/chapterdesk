These are the prompts and prompt-parts the app builds automatically and sends to the language models: story titles, introductions, headings, chapter elaboration, image generation and the language check. Every template has a built-in default (always the fallback). You can store any number of named versions — as your versions (applied everywhere) or as topic versions (applied only to chats whose environment's main topic matches). A version is active when selected below; a user version wins over a topic version, which wins over the built-in default. Revert any template to the default (or to the topic version) by picking it in the list or using Revert to default.
